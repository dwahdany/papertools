URL → APA BibTeX → APA Markdown compactor

URL → APA citation

Paste a link or identifier — DOI, arXiv, OpenReview, PubMed, ACL Anthology, Semantic Scholar, ISBN, a publisher page or any web page — and get an APA 7 reference with proper italics, plus BibTeX. Paper identifiers go straight from your browser to the public metadata APIs; ordinary web pages are read through a small stateless function on this site.

      How it works / privacy
      
      
        
    • The input is classified first: DOI (bare, doi.org or a publisher URL containing one), arXiv id or URL, OpenReview forum, PubMed id, ACL Anthology id, Semantic Scholar paper, ISBN, or a plain web page.
      • 
        
    • Paper identifiers go straight from your browser to the public APIs: Crossref for DOIs (then DataCite, then doi.org's citation data), DataCite for arXiv papers (it holds every arXiv record; Semantic Scholar is the fallback), Crossref for ACL Anthology papers, OpenReview, PubMed E-utilities and Open Library (ISBNs). The “Sources tried” line under the status shows which services answered.
      • 
        
    • Ordinary web pages (blog posts, docs, news) are fetched by a small stateless function on this site (/api/meta), because browsers cannot read most third-party pages; it returns only the page <head>, which is parsed here for citation_*, Open Graph, Dublin Core and JSON-LD metadata. That function only answers this site and is guarded by a Cloudflare Turnstile bot check, which runs silently and only shows a small widget if Cloudflare needs you to confirm you are human. Pages that allow cross-origin reads (e.g. PMLR) are read directly, and the Internet Archive is the fallback when a page cannot be fetched. If everything fails, the editor opens with the site name, URL and retrieval date pre-filled for you to complete.
      • 
        
    • arXiv papers are cited as preprints; when a published version is known, a warning shows its DOI so you can cite that instead. OpenReview sometimes blocks automated requests with an anti-bot challenge; paste the paper's arXiv link or BibTeX in that case.
      • 
        
    • Nothing is stored. The page fetcher keeps no logs of its own and only passes the page's metadata back to your browser; everything else runs in your browser. Only your option choices are kept in your browser's local storage. The lookup is put in the page address so you can bookmark or share a result.
