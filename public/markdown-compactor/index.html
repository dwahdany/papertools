Markdown table compactor

Paste Markdown with padded tables and get the same tables without alignment whitespace or long separator dashes — fewer bytes and fewer tokens for LLM prompts, identical rendering.

Load example

Paste Markdown to see how much you save. Ctrl/⌘+Enter compacts.

How it works
  • Each table row is split into cells on pipes, every cell is trimmed of spaces and tabs (non-breaking spaces are content, as in GFM), and cells are re-joined with a bare |. By default the outer pipes are dropped: | a | b | becomes a|b, which GitHub-flavoured Markdown renders identically.
  • Separator rows keep their alignment but lose the padding dashes: |:-----|----:| becomes :-|-:. Only the real separator row is collapsed; a body row of dashes is content and stays as it is.
  • Escaped pipes (\|) and pipes inside `code spans` are never treated as cell borders, and fenced ``` / ~~~ code blocks are left untouched. A cell ending in a backslash (C:\) keeps one space before the next pipe so it does not turn into an escaped pipe.
  • Tables are detected the GFM way (a header row followed by a delimiter row), including inside blockquotes and list items, whose prefix and indentation are kept. Lines that merely contain a pipe in prose are left alone; single-column tables, empty edge cells and rows whose first cell looks like a heading, quote, list item or fence (> 0.05, 1. First) keep their pipes so the table stays a table.
  • Everything else — headings, paragraphs, lists, code — passes through unchanged. If the trim option is on, trailing whitespace is removed, but a two-space hard line break at the end of a line is kept. Line endings are normalised to \n.

Everything runs locally in your browser: nothing you paste leaves this page. Options are remembered in your browser's local storage.
