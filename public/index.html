papertools

Small tools for writing papers. Everything runs in your browser — except that the URL tool fetches ordinary web pages through a small stateless function on this site; nothing is stored.

  • URL → APA citation

    Paste a link to a paper (DOI, arXiv, OpenReview, PubMed, Semantic Scholar, ACL Anthology, publisher page…) or a web page and get an APA 7 reference, with BibTeX as a bonus.

  • BibTeX → APA citation

    Convert one or many BibTeX entries into APA references with proper italics, like Google Scholar's “Cite” box. Copy as rich text, Markdown, LaTeX or plain text.

  • Markdown table compactor

    Strip padding whitespace and collapse separator dashes in Markdown tables to save tokens and bytes.
